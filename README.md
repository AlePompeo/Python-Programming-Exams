## 📌 Contenuto

Soluzioni in **Python** a esercizi e prove d'esame degli anni accademici 2013–2021, un file per esercizio, raggruppati per tema dal nome del file:

| Tema | File (esempi) |
|---|---|
| **Ricorsione** | `esercizio1Ricorsione.py` … `esercizio4Ricorsione.py`, `contaCifreRicorsione.py`, `provaRicorsione.py` |
| **Stringhe** | `eserciziostring1.py`, `palindromi.py`, `sostituzioneCaratteri.py`, `stringFind.py`, `reverseAndCount.py` |
| **Liste e matrici** | `esercizioMatrici.py`, `matrixClass.py`, `matriciCompito.py`, `inversionRow.py`, `inserisciLista.py`, `listGenerator.py` |
| **Classi** | `classDate.py`, `classTupla.py`, `matrixClass.py` |
| **Numeri e basi** | `conversioneBase.py`, `esercizioVirgolaMobile.py`, `problema4Tartaglia.py` |
| **Prove d'esame** | `n1prova18lug2013.py`, `2esercizio05-09-13.py`, `1esercizio9-02-14.py`, `3esercizio2-09-19.py`, `problema1prova2020.py`, `problema11prova2021.py`, `*provefinali.py` |

## ▶️ Eseguire un esercizio

```bash
python3 conversioneBase.py
```

Ogni file è autonomo. `testinterfaccia.py` è un esempio di interfaccia Tkinter (tabella di input), `testMatrici.py` e `test1.py` sono file di prova.
